# API Documentation

## Overview

AppZen provides comprehensive APIs that enable you to streamline your financial operations by integrating our services with your existing systems. Our APIs allow you to automate tasks such as expense management, invoice processing, and compliance checks.

Our Public APIs are compatible with popular accounting and ERP systems like Coupa, SAP, Oracle, and NetSuite, ensuring seamless integration without compatibility issues.

This documentation is organized into the following sections:

## API Structure

| Section | Description |
| --- | --- |
| [Authentication](../docs/__authentication-__.md) | How to authenticate with AppZen APIs using OAuth 1.0 and OAuth 2.0 |
| [Token Generation](../docs/__token-generation__.md) | Instructions for generating access tokens for API calls |
| [Status Code](../docs/__status-code__.md) | HTTP status codes returned by AppZen APIs and their meanings |

## Getting Started

To get started with AppZen APIs:

1. Review the [Authentication](../docs/__authentication-__.md) section to understand how to secure your API calls
2. Generate API credentials following instructions in [Token Generation](../docs/__token-generation__.md)
3. Reference the [Status Code](../docs/__status-code__.md) section to understand API responses
4. Check out the product-specific API documentation for:
   - [Expense Audit](../docs/expense-audit.md)
   - [Autonomous AP](../docs/autonomous-ap.md)
