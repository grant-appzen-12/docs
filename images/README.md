# Documentation Images

This directory contains images used in the AppZen API documentation.

## Placeholder Images

The following placeholder images need to be created and added to this directory:

1. `/images/authentication_overview.png` - Diagram showing the different authentication methods available
2. `/images/oauth1_flow.png` - Diagram showing how API key authentication works with AppZen
3. `/images/oauth2_supported_apis.png` - Diagram showing the APIs that support OAuth 2.0 authentication
4. `/images/navigate_to_api_credentials.png` - Shows the left menu with Integration expanded and API Credentials highlighted
5. `/images/api_credentials_page.png` - Shows the list of existing API credentials with their details
6. `/images/add_new_credentials.png` - Shows the form to create new API credentials
7. `/images/token_generation_flow.png` - Diagram showing the token generation and refresh flow
8. `/images/sso_login_test.png` - Screenshot showing the "Login with SSO" button and test interface
9. `/images/sso_debugging_flow.png` - Visual guide showing the troubleshooting steps for SSO issues
10. `/images/system_integration_framework.png` - Overview of the integration dashboard showing job statuses
11. `/images/integration_job_status.png` - Screen showing the status of integration jobs with successful and failed records
12. `/images/failed_records_download.png` - Shows where to find and download the failed records report

## Image Naming Convention

When adding real images to replace these placeholders, please follow these naming conventions:
1. Use lowercase with underscores for spaces
2. Use descriptive names that indicate what the image shows
3. Use .png format for screenshots and diagrams
4. Keep the same filenames as the placeholders to maintain document linking
